# DevOps Maturity Assessment Tool

A web-based tool for assessing DevOps maturity in organizations, built with Python and Streamlit.

## Features

- Interactive questionnaire covering key DevOps practice areas
- Dynamic scoring and maturity level calculation
- Visual representation of results with charts
- Customized recommendations based on assessment results
- PDF report generation

## Installation

1. Clone this repository
```bash
git clone https://github.com/yourusername/devops-maturity-model.git
cd devops-maturity-model
```
2. Create a virtual environment and install dependencies
```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
pip install -r requirements.txt
```
3. Run the application
```bash
streamlit run app.py
```
## Usage

1. Complete the assessment by answering questions in each section
2. Submit the assessment to view your results
3. Generate a PDF report for sharing or future reference
